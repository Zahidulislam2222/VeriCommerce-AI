# Public website

The homepage is complemented by fourteen dedicated pages using maintained JSON and shared responsive navigation/footer.

| Area | Pages |
|---|---|
| Product | Platform, Pricing, Documentation, Changelog |
| Company | About, Contact |
| Trust | Security, Accessibility |
| Legal | Legal hub, Privacy, Terms, Cookies, United States, European Union |

The project is developed and operated by Zahidul Islam. Public contact is [muhammadzahidulislam2222@gmail.com](mailto:muhammadzahidulislam2222@gmail.com). Contact links open the visitor's mail application; the website does not silently send a message. No street address, company registration or compliance certificate is invented.

Pricing explains available free access and separate project discussions; there is no checkout, automatic upgrade or recurring subscription system. Temporary-workspace limits remain explicit. Privacy/cookie content distinguishes browser storage, server state and unverified infrastructure retention. US/EU information uses official references and does not replace applicability assessment.

Exact routes support direct navigation/reload. Unknown routes return HTTP404 with branded recovery content; private source paths remain blocked. Accessibility combines reduced-motion, keyboard/focus and automated checks; full independent certification is not asserted.

The current site describes persistent accounts, permitted catalog/document ingestion, four-method context inspection, reviewed drafts/structured data and the read-only connector. Pricing, privacy and legal pages retain the actual limits and storage/operating boundaries; no checkout, automatic subscription or publishing permission is implied.

The [release report](RELEASE-VERIFICATION.md) separates the earlier public-page deployment (44 live browser checks, 84 artifacts, preserved backend) from the expanded release (228 artifacts, accounts/uploads/content/connector and separately scoped live/hosted checks). Every later copy or feature release needs its own build, route, accessibility, review and publication evidence.
